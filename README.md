# ガチャ屋の借金返済（仮題）

借金を抱えたガチャ屋の店主が、ガチャを回して出た景品を変動する相場で売り、借金を返していくローグライト。
現在は **Phase 1（手触りの検証）** の実装です。

## 動かし方

```bash
npm install
npm run dev      # http://localhost:5173 （--host 付きなので同じ LAN のスマホからも開けます）
npm run build    # dist/ に出力
npm run preview  # ビルド成果物の確認
npm run sim      # バランス確認（自動プレイで何週目まで返済できるかの分布）
```

Node.js は 20.19 以上（または 22.12 以上）が必要です（Vite 8 の要件）。

## デプロイ（Cloudflare）

公開 URL：https://gatyaya.momotech.workers.dev

Cloudflare Pages は Workers に統合されたため、Workers の静的アセット配信（無料枠）で公開しています。設定は `wrangler.jsonc`。

```bash
npm run deploy   # = npm run build && wrangler deploy
```

環境変数 `CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` が必要です（または `npx wrangler login`）。
GitHub への push で自動デプロイしたい場合は、Cloudflare ダッシュボードの Workers & Pages → gatyaya → Settings → Build で、このリポジトリを接続します（Build command：`npm run build`、Deploy command：`npx wrangler deploy`）。

## 画風（デザインの方針）

- **夕暮れの駄菓子屋兼トレカ屋**。ポップだけど少し不気味。ネオン（発光）表現は使わない
- 輪郭は墨色の太線＋ずらしたベタ影。配色は `src/config.ts` の `PAL` に集約
- ガチャ機は付喪神（目がハンドルを追う・口が排出口・レア排出で目を見開く）
- 景品はグッズとして表示（缶バッジ〜フィギュア・ホロカード。名札にレア度とシリーズ）
- 不気味要素：お札、人魂、棚の暗がりからのぞく目、返済日の取り立て屋、差押のお札
- 妖怪モチーフは民話の一般的な意匠（提灯お化け・猫又・一つ目など）に留め、特定作品のキャラクターは描かない
- 縦長スマホでは画面の高さを端末に合わせて伸ばし（9:16〜約 20:9）、safe-area（ノッチ・ホームバー）も避ける

## ホーム画面に追加（PWA）

公開 URL をスマホのブラウザで開き、共有メニューの「ホーム画面に追加」でアプリのように全画面で起動できます。一度開けばオフラインでも遊べます（`public/sw.js`）。アイコンは `public/icon.svg` から PNG を書き出しています。

## 技術構成

- TypeScript + Vite + Phaser 3（Matter.js 物理）
- 効果音は `src/core/audio.ts` で **すべてコード合成**（外部音源なし）。起動時に AudioBuffer を作り、`pointerdown` から即時再生
- 画像はすべて Canvas で生成（`src/ui/textures.ts`）、フォントは端末のシステムフォント
- 保存は localStorage（すべて try/catch）

## Phase 1 で実装したもの

- 手回し式ガチャ：ハンドルを指で回す（30° ごとに「ガリ」、1 周で「ゴトン」＋画面揺れ＋煙）。逆回転は無効（ラチェット）
- カプセルの物理（瓶の容量 20）。**合体は廃止**し、代わりに「夜のうちに化ける」：開けずに残したカプセルが閉店後にまれに 1 段階上がる（N→R 6%／R→SR 5%／SR→SSR 3%／SSR→UR 1.5%、仮値）
- 瓶の遊び：同じレア度のカプセルが 3 つ以上くっつくと自動で「色違いカプセル」に（レア度は上がらない。中身は色違いグッズで売値 ×3.6、4 つ以上でおまけコイン）。「まぜる」ボタンで瓶を揺する（1 日 3 回）
- 開封演出（レア度が高いほど溜め・揺れ・光が大きい）。グッズがくるくる回って飛び出し、名札が付く。SSR 以上は鑑定書付き
- 景品 30 種（架空 3 シリーズ × 5 レア度 × 2 種）。グッズの形は 7 種類（缶バッジ・シール・キーホルダー・アクスタ・ぬいぐるみ・フィギュア・ホロカード）
- 相場：シリーズごとに週単位の値動きパターン（大波 ×2〜×6／小波／じり貧／乱高下）と、景品ごとの飽和（1 個売るごとに ×0.92、毎日 50% 回復）
- 売却画面（記号で値動き表示、数値は景品タップ時のみ）
- バイト「カプセル詰め」（20 個以上で瓶容量 +1／今週のみ）
- 1 日 6AP、閉店のレジ締め演出、7 日ごとの返済、ゲームオーバー、localStorage 保存/再開

## 噂とイベント

- 毎朝「瓦版」に噂（1〜3 件）と速報が出る。窓に貼った瓦版をタップで読み直せる。定義は `src/game/events.ts`
- イベント：TV で紹介（2 日 ×1.8〜2.6）／生産終了（以後 ×1.4、ガチャで出にくい）／偽物の流通（3 日 ×0.4）／販売禁止（3 日売れない。闇ルートなら半値・30% で摘発され罰金）
- 噂は 2〜3 日後のイベントの予兆か、今週の値動きのヒント。的中率は約 6 割（縁起物「情報屋の耳」で +20%）。販売禁止は必ず本物の噂で予兆が出る

## 縁起物（レリック）

Slay the Spire のレリックにあたる。店の壁に飾られ、タップで効果を表示。定義は `src/game/relics.ts`（データ＋フック）。

- 入手：ガチャの「黒いカプセル」（0.4%、3 つから 1 つ）／返済後の取り立て屋（並・上 2 つ＋訳あり 1 つから 1 つ）
- 19 種：並 9・上 6・訳あり 4（訳ありは強いが欠点つき）
- TODO：夜の行商人（コインで買う）、バイト高得点のご褒美、目利き

## 仕様書からの変更（相談のうえ決定）

- 3.2 の「同じレア度の接触で合体」を廃止し、「夜のうちに化ける」に置き換え（SSR を引いたときの嬉しさを守るため）
- 景品の表示をトレカからグッズ 7 種類に変更
- 瓶の中で同じレア度が 3 つ以上くっつくと色違いになる合成と「まぜる」ボタンを追加
- 相場（4.2 のトレンド係数）を週単位のパターン制に変更
- レリック「合体の達人」は「夜更かし（化ける確率アップ）」に置き換え予定（フックは `onNight`）

## 仕様から判断した点（要確認）

- **出店の AP**：「売りに行く」は入るたびに 1AP。戻ると店じまい（1 日 1 回扱いにするかは未確定、`MarketScene.ts` に TODO）
- **AP 0 のとき**：自動閉店にはせず、ガチャ（AP 不要）と開封は続けられる。閉店ボタンが点滅して促す
- **閉店の誤操作防止**：AP が残っている場合は 2 回押しで閉店
- **バランス**：初期コイン 150、ガチャ 1 回 20、返済ノルマは初回 1,000・毎週 ×2.0、5 週返済で町の借金完済。`npm run sim` のシミュレーターで調整（縁起物を取るプレイで完済率 約 70%、縁起物なしで約 5%）
